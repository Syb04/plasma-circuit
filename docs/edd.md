# EDDの使い方

Equation-defined deviceは、端子間の導電電流と蓄積電荷を式で与える素子です。各枝について正端子→負端子の電圧を `Vk`、同じ向きの導電電流を `Ik` とし、総端子電流は次の関係を満たします。

```text
Itotal,k = Ik(V1, V2, ...) + dQk(V1, V2, I1, I2, ...)/dt
```

`Ik` の参照は総電流ではなく導電電流です。パラメータと中間式を展開し、ngspiceの数式電流源と電荷定義コンデンサに変換します。

## 非線形電荷の例

「非線形電荷EDD」プリセットは次のモデルです。

```text
I1 = V1/R
Q1 = C0*V1 + alpha*V1^3
R = 1000 Ω
C0 = 1e-6 F
alpha = 1e-7 C/V³
```

このとき微分容量は `C0 + 3*alpha*V1²` です。負の電圧では3乗の電荷も負になります。初期版はこの符号と電荷の微分電流を実solverで検証しています。

部品を選び、枝の端子名・I・Qを変更して「枝を適用」を押します。「定数パラメータ」「中間式」はJSONオブジェクトを編集して適用します。枝を追加すると `V2`、`I2` などを参照できます。端子を変更して削除した場合、その端子の配線も外れます。

## 式と単位

- 電圧はV、導電電流はA、電荷はC、時間はsです。係数の単位はモデル作成者が整合させます。
- `+ - * /`、`^` または `**`、比較・条件式を使用できます。
- `exp`、`log` / `ln`、`log10`、`sqrt`、`abs`、三角・双曲線関数、`min`、`max`、`limit`、`if`、`pow`、`pi`、`e`、`time` を使用できます。
- 定数として判定できる整数のべき乗は負の底の符号を保持します。非整数・動的指数は非負の底を前提とします。複素数の式には対応しません。
- 未定義変数、循環参照、Pythonコード、外部ファイル参照や制御コマンドは受け付けません。

数学的に不連続な式や負の微分容量を持つ式は、解析の種類・初期状態・刻みによって収束しないことがあります。計算エラーと生成ネットリストは実行履歴から確認できます。

結果には枝の導電電流、総電流、電荷を保存します。結果画面の単位選択で電流・電荷を表示し、X–Y表示でQ–Vの関係を確認できます。

QUCS系EDDの概念については [Qucs-S EDD documentation](https://qucs-s-help.readthedocs.io/en/legacy/DModel.html) を参照してください。QUCSの全言語・全構文との完全互換を意味するものではありません。
