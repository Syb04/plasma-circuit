# 初期版の仕様

## 目的と利用

社内チームがブラウザでアナログ回路とプラズマ等価回路を構築し、計算・可視化・保存できる環境を作る。実行環境はDocker、フロントエンドはReact、回路計算はPySpice / ngspice、永続保存はPostgreSQLとする。

ログインは設けず、保存・実行時の社員番号を必須とする。社員番号は先頭の0を保持する文字列。共同編集で古い版を上書きしないよう版番号で保存競合を検出する。

## 回路と解析

- MOSFETを除くngspiceの基本アナログ素子を部品カタログに用意する。パラメータ・モデルとサブ回路を編集できる。
- EDDはQUCS系の電流・電荷定義を想定し、各枝の `I` と `Q` を定義する。複数端子枝、他枝電圧・導電電流への依存、共通パラメータと中間式を扱う。
- 電荷の微分電流を含む実計算をngspiceで行う。式は制限した数学言語として評価する。
- DC動作点、DCスイープ、AC、過渡解析を実行する。電圧・電流・電荷・電力に単位を付けて表示する。
- 配線は端子接続で表現し、見た目の交差から接続を推測しない。

## プラズマの基準条件

初期版はAr・O₂を単独で扱い、主対象はCCP。CF₄の採用は保留する。基準は40 MHz、駆動電極に加えるRF正弦波ピーク250 V、300 mmウェハー側をRFカソード、有効アノード／カソード面積比5、10 mTorr、電極間隔50 mm、ガス温度300 K。主な壁・電極材はシリコンとし、表面の酸化・被覆状態と表面温度は独立に記録する。

無DC給電の定常境界として周期平均電極電流を0にし、DC自己バイアスを求める。シース電荷・電流とバルク等価回路を構成し、粒子・電子エネルギー収支を使うグローバルモデルと連成する。

電極面積、プラズマ体積、粒子の壁損失面積を区別する。幾何学的な初期値や簡略化はモデル設定と結果に記録する。

検証時の圧力・周波数は参考文献の条件に合わせて変更できる。装置の基準条件と文献再現用の条件を別のケースとして保存する。電圧の定義、形状、電極材質、表面反応、中性粒子背景等も文献条件と照合し、残る差分を明記する。文献条件での再現確認と、40 MHz・面積比5・シリコンの基準条件への適用確認を区別する。

## 初期実装の境界

通常回路のEDDと、専用CCP設定テンプレートを提供する。専用CCPに任意の回路図を自動的に連成する機能は後続の開発対象とする。

標準グローバルモデルは純Arの縮約定常モデルから検証する。O₂は等価回路と反応データ登録のインターフェースを先に用意し、出典・適用範囲・負イオン・解離種・壁反応を確認した反応セットを追加する。反応データがない状態でガス名だけから密度や温度を生成しない。O₂のモデル候補とCF₄の保留方針は[文献調査](oxygen-literature-review.md)に記録する。

巨視的な時間発展、放電着火、シース加熱、二次電子、空間分布と実験値による較正は後続の物理モデル拡張とする。初期版の結果にはモデル名・版・出典・仮定・収束診断を付ける。

## 保存と再現性

回路の各版、入力者、実行時の回路・式・モデル・解析条件、ソルバーと実装の版、結果配列・診断・ネットリストを保存する。過去の計算は回路の後の編集から独立したスナップショットとして扱う。

ジョブはキューで実行し、待機・実行・成功・失敗・停止・時間超過を区別する。結果は波形・数値・CSVで確認する。混合ガス、認証・権限管理、PIC・流体などの空間モデルは初期版の範囲外。
