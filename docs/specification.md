# 実装仕様とモデルの境界

## 目的と利用

社内チームがブラウザで回路とプラズマ等価回路を構築し、計算・可視化・保存する。Docker、React、FastAPI、PostgreSQL、Redis/RQを使い、回路の波形は実際のPySpice/ngspiceで計算する。外側の粒子・エネルギー収支と時間積分にはSciPyを使う。

ログインは設けない。回路保存、実行、研究作成・再開、パッケージ読込では社員番号を必須とし、先頭の0を保持する文字列で保存する。社員番号は操作履歴であり、認証・アクセス制御ではない。版番号で古い回路による保存・実行の競合を検出する。

## 回路と解析

- MOSFETを除くngspiceの基本アナログ素子、数式電源、伝送線、サブ回路、EDD、2端子 `PLASMA` を用意する。
- 素子・波形・解析条件の数値欄は指数表記の入力途中を保持し、有限のSI数値として保存する。詳細ダイオードは部品ごとのネイティブDモデルでIS/N/RS/BV/IBV・容量・走行時間・温度依存を指定し、モデル名で参照する従来のD素子も維持する。[入力・設定仕様](circuit-parameters.md)を参照。
- EDDは各枝の導電電流 `I` と電荷 `Q` を定義し、複数枝、他枝電圧・導電電流、共通パラメータ、中間式を扱う。端子電流 `I+dQ/dt` を実際にスタンプする。式は制限した数学言語である。
- 通常回路はDC動作点、DCスイープ、AC小信号、過渡解析を実行する。周期RFの大信号Zと通常のAC小信号Zを区別する。
- 端子の明示接続で配線する。見た目の交差から接続を推測しない。

| API解析種別 | UI名 |
| --- | --- |
| `ccp` | CCP・固定プラズマ |
| `global` | プラズマ・グローバル解析 |
| `global_transient` | プラズマ・時間発展0D |
| `radial` | 径方向・分布回路解析 |

## プラズマの基準条件と電圧

対象は単独Ar・O₂。CF₄の採用は保留し、既存データの読込互換性を維持する。基準条件は40 MHz、300 mmウェハー側の駆動カソード、有効接地／駆動面積比5、10 mTorr、間隔50 mm、ガス温度300 K。主な材料候補はSiだが、表面状態・温度・反応係数は独立した入力であり、Siの検証済み既定係数はない。

| 実行経路 | `rf_peak_voltage=250` の意味 | DC境界 |
| --- | --- | --- |
| 空の専用CCPテンプレート、外部回路なし | 電極側に加える主RFのピーク250 V | 周期平均電極電流0になるVdcを外側根探索で求める |
| 専用テンプレート＋`external_circuit` | 理想電源の主RFピーク250 V | 実際の接続を解析。DCブロック時は容量の周期電荷平衡を求める |
| 通常回路図＋`PLASMA` 1個 | 回路図の電圧源波形が駆動条件。電極振幅は計算結果 | DCブロック時は周期電荷平衡、DC給電時は接続に従う平均電流 |

理想電源と50 Ω出力抵抗の負荷側RF測定面、さらに電極側測定面を区別する。ピーク、RMS、ピーク間、総平均電力、基本波電力も別の量として保存する。電極面積、プラズマ体積、粒子壁損失面積、O₂円筒化学モデルの表面積を区別する。

専用テンプレートは `document.parameters.builtin_ccp_template=1` で部品・配線が空の設定文書である。部品を追加したまま計算するとエラーにする。外部回路の編集には通常回路図の2端子 `PLASMA`（駆動p・帰還n）を使う。複数プラズマの連成は未対応。

2周波数RFと周期パルス包絡は共通基本周期の整数倍で指定する。RF包絡の `pulse_off_fraction` は電圧振幅比、マクロ0Dの同名入力は平均電力比である。時間刻みは最速の搬送周波数に対して設定し、周期数は共通基本周期で数える。

## 実装した物理モデル

| モデル | 計算するもの | 主な境界 |
| --- | --- | --- |
| 固定CCP | matrix-sheath I/Q、Drude R/L、電極波形、DCバイアス、RF収支 | 空間平均、有効単一正イオン、電子反発シース |
| Ar定常0D | 基底状態電離と集約励起、粒子・電子エネルギー収支、RFとの反復 | 1〜7 eV探索、準安定種なし |
| O₂定常0D | 文献由来48粒子反応、16励起損失項、流量・壁閉包、指定総吸収電力またはRF連成 | 縮約エネルギー閉包。全反応のエネルギー移送ではない。k20の範囲は1<Te<4.5 eV |
| ユーザー定常0D | 出典付き反応表、準中性粒子・電子エネルギー収支 | 登録データは未検証。粒子専用表をエネルギー閉包として使わない |
| 時間発展0D | Ar/O₂の密度・電子エネルギー・ガス温度をBDFで実積分 | 既に粒子を含む準中性状態。RFは明示した時刻で再計算する平均電力の保持近似 |
| 電子輸送 | 明示νまたは出典付き断面積×Maxwellian/表形式EEDFの積分 | Boltzmann方程式を解かない。輸送EEDFは既存化学係数を自動置換しない |
| 表面・二次電子 | 電極・壁の独立係数、面積重み付け、局所電極二次電子電流・加速電力 | 材料名から係数を生成しない。二次電子の運動論・雪崩なし |
| 移動シース加熱 | Maxwellian反射境界の不可逆仕事と圧力仕事の分離、有効直列抵抗を介したRF反復 | 平面・一定入射リザーバーの縮約閉包。運動論検証なし |
| IEDF | 実RFシース波形中の粒子軌道、任意の一定断面積電荷交換、イオン・高速中性粒子分布 | 固定幅・一様電場。電場へ粒子を戻さない |
| 径方向回路 | 同心円環の線形RF電圧・位相・吸収電力とシート損失、適用範囲診断 | 一様指定密度。径方向密度・温度・反応輸送や完全電磁界を解かない |

式・出典・入力例は[プラズマモデル](plasma-models.md)、[電子・表面モデル](electron-surface-models.md)、[IEDF・径方向モデル](ion-radial-models.md)に記録する。混合ガス、着火、PIC、自己無撞着な空間輸送、完全なBoltzmann/EEDF解、実験による係数較正は実装範囲外。

## 数値診断と参照比較

ジョブの `succeeded` は計算プロセスの完了を表す。結果の `converged` は周期性、電流・電力収支、化学収支、積分終了条件などの数値診断を表す。モデルの適用範囲診断や文献条件への適合、実験精度とは別である。

RFでは最後の2共通周期の可変刻みを保存し、周期積分で平均量を求める。任意の数値精細化ではRF点数・周期数、径方向セル数、ODE許容差を変更し、基準結果を保持したまま主要指標を比較する。追加計算の失敗、比較条件なし、未収束を合格にしない。

参照CSV/JSONは測定定義、材料、圧力、周波数、出典、単位、任意の不確かさを保存し、対応する指標の数値差を返す。参照との一致だけでモデル全体を実験検証済みにしない。基準40 MHz・面積比5・Si条件と文献再現条件を別ケースで保存し、残る差分を明記する。

## 研究・保存と再現性

1〜2軸、最大100ケースの直積スイープを通常のキューで実行し、各入力スナップショット、失敗、停止、再試行を保持する。再開は失敗・時間超過・停止したケースの新しいrunを作り、以前の試行を上書きしない。2〜4保存結果の入力差・波形と、適用可能なRF位相合わせを提供する。

回路各版、入力者、実行時の式・モデル・条件、ソルバー・実装版、結果・残差・ネットリストを保存する。過去のrunは後の編集から独立したスナップショットとし、結果を圧縮してPostgreSQLへ保存する。状態は `queued/running/succeeded/failed/canceled/timed_out`。

解析パッケージは入力、モデル・出典、実装ハッシュ、結果をJSONで書き出す。読込時に形式・スキーマ・SHA-256を検証して新規回路と来歴を保存し、再計算を要求する。チェックサムは改変検出であり、発行者の認証ではない。保存結果は新しい成功runとして取り込まない。

操作と実行例は[解析・研究ワークフロー](analysis-workflows.md)、HTTP契約は[CONTRACT](CONTRACT.md)、検証証跡は[検証状況](validation-status.md)を参照する。
