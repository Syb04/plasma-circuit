# 回路素子の指数入力と詳細ダイオード

部品を選択して数値欄に `4e7`、`1E-9`、`2.5e+2` のように入力できます。正負の指数、符号付き数値、小数に対応しています。`1e-` のような入力途中の文字も保持し、完成した有限の数値を保存・計算に使います。入力途中・範囲外の数値を表示している欄があれば、保存・計算を止めてその欄を示します。

電圧源・電流源の「電源波形・2周波数RF」で、正弦波の周波数や振幅、パルスの立上り・立下り・ON幅・周期、RF包絡などを設定できます。抵抗・容量・インダクタ、PLASMA部品と解析条件の数値欄も指数入力を扱います。欄に示された単位で入力し、保存・ソルバーへの引渡しにはSI数値を使います。例えば `4e7 Hz` は入力欄には `4e7`、`1e-9 s` は `1e-9` と入力します。過渡解析の時間単位を切り替えたときは、物理時間を保持します。

電源のDC値と波形の開始値は別に指定できます。値が異なるとngspiceは動作点でDC値を使う旨の注記を出します。この特定の注記だけをPySpiceがエラーとした場合は、ngspiceが実際に計算した指定解析のデータを取得して注記をログに残します。動作点のDC値や過渡波形は指定のままで、別の計算エラー・非有限値・空の結果は失敗として扱います。

パレットの「半導体」から **ダイオード（詳細設定）** を追加します。通常の「ダイオード」は、従来どおりモデル名で登録済みSPICEモデルを参照できます。

| 記号 | 設定 | 単位 | 入力範囲 |
| --- | --- | --- | --- |
| IS | 飽和電流 | A | 正 |
| N | 理想係数（放射係数） | 無次元 | 正 |
| RS | 直列抵抗 | Ω | 非負 |
| BV | 逆ブレーク電圧の大きさ | V | 正 |
| IBV | BVにおける逆方向電流の大きさ | A | 正 |
| CJO | ゼロバイアス接合容量 | F | 非負 |
| VJ | 接合電位 | V | 正 |
| M | 接合傾斜係数 | 無次元 | 非負 |
| TT | 走行時間 | s | 非負 |
| EG | エネルギーギャップ | eV | 正 |
| XTI | 飽和電流の温度指数 | 無次元 | 有限 |
| FC | 順方向接合容量係数 | 無次元 | 0以上1未満 |
| TNOM | モデル基準温度 | °C | −273.15より大きい |

接合容量・走行時間・温度依存の欄は詳細セクションで開きます。面積倍率は全体の部品パラメータで、正の値を指定します。

追加時には IS=`1e-14`、N=`1`、RS=`0.1`、CJO=`1e-12` を設定します。空欄にしたモデルパラメータはモデル定義から外し、ngspiceの既定値を使います。BVは追加時には未指定で、逆降伏を設定する場合に正の電圧を入力します。Nと接合傾斜係数Mは別のパラメータです。

詳細ダイオードも回路JSONの `kind` は `D`、端子は `p`（アノード）と `n`（カソード）です。

```json
{
  "id": "d1", "kind": "D", "label": "D1", "ports": ["p", "n"],
  "parameters": {
    "area": 1,
    "model_parameters": {"IS": 1e-12, "N": 1.5, "RS": 0.5, "BV": 75, "IBV": 1e-3, "CJO": 1e-11, "TT": 1e-8}
  }
}
```

各部品に固有の `.model … D(...)` を生成して実際のngspiceに渡します。`model_parameters` が存在するD素子はこの専用モデルを使い、同時に指定された `model` 名は使用しません。専用モデル名は既存モデル名と重複しないように生成します。パラメータ・面積倍率は回路の版と実行スナップショットに保存し、生成したモデル定義は結果のネットリストで確認できます。

TNOMはモデルパラメータの基準温度です。今回の設定欄は素子温度や解析の動作温度を変更する機能を追加しません。
