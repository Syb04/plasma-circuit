# ノード名と波形の凡例

回路図で端子名（`p`、`n`、`p1`など）または配線をクリックすると、その電気的なノードを選択できます。設定欄の「端子・ノード名」に名前を入力し、「ノード名を適用」を押します。部品を選択し、「対象の端子」から選ぶこともできます。

例えば電源側を `RF入力`、電極側を `電極` とすると、対GND電圧の波形を `V(RF入力)`、`V(電極)` と表示します。AC解析では振幅と位相にも名前を反映します。凡例の表示切り替え、ツールチップ、X–Yプロットの信号選択と軸、CSV、研究・比較画面も同じ表示名を使用します。元の信号IDは凡例のツールチップや結果のJSONで確認できます。

## 名前の範囲

- 明示的に配線でつながる端子は同じノードです。どの端子から編集しても、そのノード全体の名前が変わります。
- 全てのGND記号は同じ接地ノードです。4端子同軸の `n1` と `n2` は素子内で同じシールドノードです。シールド接地の2端子版は、見える内部導体端子 `p1` と `p2` を個別に選びます。
- 配線の交差だけでは接続しません。名前も電気的な接続を作りません。
- 名前は前後の空白を除いた1〜100文字です。日本語、英数字、空白や記号を使用できます。改行・制御文字は使用できません。
- 別のノードに同じ名前は付けられません。異なる名前を持つノード同士を接続するときは、先に片方の名前を解除してください。

「ノード名を解除」、または空欄にして「ノード名を適用」で名前を外せます。「元に戻す」「やり直す」にも対応します。部品の複製ではノード名を追加しません。名前を付けた端子そのものを削除すると、その端子に付けた名前も外れます。回路図の移動・回転では名前を保持します。

## 計算結果と保存

名前は回路の版と実行時のスナップショットに保存し、結果には計算時の表示名を記録します。名前を変更してから新しく計算すると、その計算の凡例へ反映します。過去の計算結果とCSVは計算時の名前を保持します。名前のない既存の結果は従来の `V(n1)` などで表示します。

ノード名は表示用です。ngspiceのネットリスト、数値、内部の信号名・summaryキー・SPICEモデル定義は名前によって変更しません。通常回路のノード電圧は対GND電圧で、名前付きの接地ノードは0Vの波形を表示します。既存の未命名信号と表示名が重なった場合は、元の信号IDを添えて区別します。

CCP・RF連成グローバル解析では、名前を付けた回路ノードの対GND電圧を追加して表示します。従来の `V(cathode)` や `V(source_port)` は帰還電極・電源ポートとの電位差である場合があるため、名前付きの対GND電圧とは区別して保持します。電流、電荷、シース電位差などの物理信号はそれぞれの元の名前を保持します。
