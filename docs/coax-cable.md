# 同軸ケーブル

部品パレットの「伝送線」から同軸ケーブルを配置します。次の2種類があり、寸法・材料・損失モデルは共通です。部品を選択すると設定と線路定数を表示します。指数表記も入力できます。

| 部品 | 表示する端子 | シールドの接続 |
| --- | --- | --- |
| 同軸ケーブル（従来版、`COAX`） | `p1/n1`、`p2/n2`の4端子 | `n1/n2`を外部で接続。内部では同じシールド基準として扱う |
| 同軸ケーブル（シールド接地、`COAX_GND`） | 入力`p1`、出力`p2`の2端子 | 内部で回路のGNDへ接続 |

「同軸ケーブル — 40 MHz」と「同軸ケーブル（シールド接地）— 40 MHz」のプリセットを用意しています。どちらも1 Vピーク、50 Ω電源抵抗・50 Ω負荷、長さ1 mの線路です。従来版の保存モデル・配線はそのまま読み込めます。

入力側は `p1/n1`、出力側は `p2/n2` です。`p` は内部導体、`n` はシールド基準です。**シールド径は外径ではなく、誘電体に接する内径**を指定します。このTEMモデルでは両端のシールド基準を共通化し、両導体の抵抗・内部インダクタンスを差動ループに合算します。外部コモンモード電流や別々の接地電位を解くモデルではありません。

シールド接地版では `n1/n2` は表示せず、電圧を `p1−GND`、`p2−GND` として計算します。電源・負荷の戻り端子は通常どおりGNDへ配線してください。内部導体の `p1/p2` が接地されるわけではありません。4端子版でシールドをGNDへ接続した回路と、同じ回路モデルで計算します。4端子版を基準電位の異なるノードへ接続する場合は、その基準に対する電圧となり、接地版とは条件が異なります。

| 入力 | 初期値 | 保存キー・SI単位 |
| --- | --- | --- |
| 内部導体直径 | 1 mm | `inner_diameter_m`、m |
| シールド内径 | 3.35 mm | `shield_inner_diameter_m`、m |
| 長さ | 1 m | `length_m`、m |
| 誘電体の比誘電率 | 2.1 | `relative_permittivity` |
| 誘電体の比透磁率 | 1 | `relative_permeability` |
| 誘電正接 | 0.0002 | `loss_tangent` |
| 内部導体抵抗率 | 1.724×10⁻⁸ Ω·m | `inner_resistivity_ohm_m`、Ω·m |
| シールド抵抗率 | 1.724×10⁻⁸ Ω·m | `shield_resistivity_ohm_m`、Ω·m |
| シールド厚さ | 0.15 mm | `shield_thickness_m`、m |
| 損失の基準周波数 | 40 MHz | `reference_frequency_hz`、Hz |
| 線路の分割数 | 32 | `segments`、整数 |

直径・長さ・厚さ・比誘電率・比透磁率・基準周波数は正、シールド内径は内部導体直径より大きい値です。抵抗率は非負、誘電正接は `0 ≤ tan δ < 1`。抵抗率0はその導体を理想導体として扱い、誘電正接0は誘電体損失を省略します。分割数は1〜256、回路内の同軸ケーブル合計で512区間までです。

## 線路定数と損失

内部導体半径を `a`、シールド内半径を `b` とすると、単位長さあたりの外部インダクタンスと容量は次のTEM式を使います。

```text
L′ = μ₀ μr ln(b/a) / (2π)
C′ = 2π ε₀ εr / ln(b/a)
Z₀,TEM = √(L′/C′)
vTEM = 1 / √(L′C′)
τTEM = 長さ / vTEM
```

UIのTEM特性インピーダンス・伝搬遅延は外部L′とC′から求めた無損失の値です。初期値では約50.021 Ω、4.834 ns/mになります。実際の位相には導体の内部インダクタンスも影響します。

導体は非磁性の中実内部導体と平滑な円筒シールドを仮定します。誘電体のμrは外部L′に適用し、金属のμにはμ₀を使います。内部導体は円柱のBessel解、シールドは実際のDC断面積を保つ平板表皮近似から、基準周波数における複素内部インピーダンスを求めます。撚線、編組、めっき、表面粗さは含みません。

各区間は受動π型RLC回路です。導体のDC抵抗に `Rskin || Lskin` を直列接続して、DC抵抗と基準周波数の複素内部インピーダンスを合わせます。誘電体は並列容量と直列RCの緩和枝で表現し、基準周波数で `Y′ = ωC′(tan δ + j)` に合わせます。誘電体損失を定数の漏れ抵抗に置き換えないため、DCでは誘電体を通る漏れ電流を生じません。

線路定数の減衰表示は基準周波数の分布定数から `γ = √(Z′Y′)`、`α[dB/m] = 20 Re(γ)/ln(10)` を計算した値で、端子の不整合による反射損失は含みません。初期値の導体RF抵抗は約0.6875 Ω/m、減衰は約0.06042 dB/mです。

**損失の周波数依存は基準周波数に合わせた近似です。** 正確な広帯域の表皮・誘電体分散モデルではありません。高調波や急峻なパルスでは基準周波数と分割数を変えて感度を確認してください。分割数による遅延・位相の離散化誤差もあります。基準周波数で1区間の位相が0.2 radを超える場合は、画面に分割数を増やす案内を表示します。周波数スイープの上限やパルスの高周波成分も考慮して分割数を選んでください。

ngspiceのLTRAはRLC/RC/LC/RGの組合せに制約があり、TXLは過渡解析用です。この部品は標準R/L/Cを生成し、PySpice/ngspiceでDC・AC・過渡・外部回路付きCCPを計算します。[ngspiceマニュアル](https://ngspice.sourceforge.io/docs/ngspice-html-manual/manual.xhtml)の伝送線モデル§6.2、§6.4を参照。

## 結果・保存・研究

`V(<id>:input)`、`V(<id>:output)` はそれぞれ内部導体−シールド電圧です。`I(<id>:input)`、`I(<id>:output)` はいずれも**ケーブルへ流れ込む向きを正**とします。ACでは振幅・位相を表示します。

`P(<id>) net input` は両端からの正味入力電力です。過渡では蓄積エネルギーの増減を含むため、瞬時の発熱量とは一致しません。ACではピークフェーザから求めた平均電力です。周期CCPでは周期平均の正味入力電力も `model_metadata.coax_cables.<id>.periodic_net_input_power_w` に記録します。

すべての入力は回路版・実行スナップショットに保存し、計算に使った線路定数・仮定・分割数を `model_metadata.coax_cables` に記録します。内部の分割回路の信号はグラフから省き、生成ネットリストは結果に残します。「研究・比較」では寸法・材料・基準周波数・分割数をスイープできます。UIのmm/MHzはAPI送信時にm/Hzへ変換します。

結果には部品の種類 `component_kind` とシールド基準ノード `shield_reference_node` も記録します。シールド接地版の基準ノードは `"0"` です。2種類の同軸を同じ回路に置く場合も、分割数の合計上限512を共通に適用します。

線路定数プレビューは読取専用の `POST /api/coax/preview` で、保存・社員番号・計算ジョブを必要としません。
