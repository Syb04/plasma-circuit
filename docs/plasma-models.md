# CCP・グローバルモデルの仕様と適用範囲

これはプラズマモデルを接続して検証するための研究用初版です。計算に使う
回路ソルバーは実際のPySpice/ngspiceであり、固定波形や密度のダミー結果を
返しません。一方、モデルの実験との一致や定量的予測精度は未検証です。

## 組み込みCCP設定テンプレート

`document.parameters.builtin_ccp_template = 1`、部品・配線が空の設定専用
テンプレートで使用します。任意のユーザー編集回路図を連成計算する機能とは
別です。設定テンプレートに部品・配線を追加すると、無視せずエラーにします。
実行結果には実際に生成・計算したネットリストを保存します。

初期版の対象は単独Ar/O₂（CF₄は採用保留）。基準は40 MHz、250 Vpeak、直径300 mmの駆動カソード、
接地アノード/カソード有効面積比5、10 mTorr = 1.333223684 Pa、
50 mm、300 Kです。直径から計算する円板面積は0.0706858 m²、接地有効面積は
0.353429 m²です。体積の既定値は円板面積×間隔 = 0.00353429 m³ですが、
有効体積と壁損失面積は独立に変更できます。

| 設定 | 既定値・意味 |
|---|---|
| `electron_density_m3` | 1e16 m⁻³、固定条件またはグローバル探索初期密度 |
| `electron_temperature_ev` | 3 eV、固定条件または探索初期温度 |
| `momentum_collision_frequency_hz` | 1e7 s⁻¹、νmの入力仮定。2πを掛けない |
| `ion_mass_amu` | Ar:39.948、O₂:31.998、CF₄:69.006（CF₃⁺を仮定） |
| `electronegativity` | 0、負イオン総電荷密度/電子密度 |
| `wall_edge_factor` | 0.5、平均密度に対するシース入口の密度比の入力仮定 |
| `plasma_volume_m3` | 円板面積×間隔。ユーザー指定優先 |
| `wall_loss_area_m2` | 駆動＋接地有効面積。ユーザー指定優先 |
| `cycles`, `points_per_cycle` | 80、256。範囲16〜120周期、64〜512点/周期 |
| `max_global_iterations` | 18。範囲3〜40 |

**νmの既定値は出典付きのガス別衝突係数ではありません。** 圧力・EEDFから
νmを求める機能は将来の拡張です。固定条件のO₂/CF₄は入力した有効イオン質量・
νm・負イオン密度比による縮約回路であり、化学反応の予測ではありません。

## 回路・EDDの方程式

バルクはDrudeの直列R–Lとして

```
L = me * gap / (e² ne Acathode)
R = νm L
ni = ne (1 + electronegativity)
uB = sqrt(e Te / mi)
Iion = e A ni wall_edge_factor uB
Ielectron = e A ne wall_edge_factor sqrt(e Te / (2π me)) exp(Vs/Te)
Vs = Vmetal − Vplasma
```

冷たい一様イオンのmatrix-sheathでは、電子反発電圧が十分大きいとき
`Qmetal ~ −A sqrt(2 ε0 e ni_edge (−Vs))`です。崩壊時の微分の特異点を避け、
熱電圧TeのoffsetとDebye容量の正電圧側への滑らかな接続を使います。
具体的な式はネットリストと`sheath_charge`にあり、表示電荷にも同じ式を
使用します。探索時の順方向Boltzmann電流は熱流束の30倍へ滑らかに制限します。
正の電子シースの物理は未対応で、崩壊の頻度をdiagnosticsに記録します。

シースは導電電流`Ielectron−Iion`と電荷`Qmetal`によるI/Q素子です。
ngspiceのB電流源と、正規化した電荷ノードでスタンプし、端子電流は
`I + dQ/dt`です。電荷ノード電圧を`Q/1e-8`、補助容量を`1e-8 F`とし、
容量電流をF電流源で端子へ戻します。これにより小さなCoulomb値を内部で
十分な電圧尺度に保ちながら、元の電荷微分を実際のngspiceで計算します。
駆動電極のRF振幅を250 Vpeakに固定し、DC給電がない条件として
**周期平均電極電流が0になるVdcをSciPyの外側根探索で求めます。**
面積比による電圧則は探索区間の初期推定だけに使い、結果の自己バイアスは
実際のRF過渡解析から計算します。

計算開始時には8 RF周期で振幅を滑らかに上げます。
`r=min(t/(8 RF周期),1)`、振幅係数`r²(3−2r)`のsmoothstepを使い、
8周期後は指定振幅と完全に一致します。
最後の2周期だけを表示・保存します。ngspiceの可変刻み全点で周期積分し、
電子電流の狭いパルスを一様間引きで落としてから平均しません。
DC電流残差・周期間電流RMS差・電力残差を保存し、未収束は表示します。
電流・両シース電圧・電荷の周期間相対RMS差を2%未満、RF電力予算の相対残差を
1%未満とする初期数値基準です。DC平均電流は駆動電極のBohmイオン電流の
1%未満（最小許容値1 µA）を基準にします。粗い刻みでは数値散逸によって
電力予算がずれる場合があるため、定量比較の前に256/512点などで刻み収束を
確認してください。実際の残差を結果に保存し、モデルの物理精度とは区別します。

電流の正方向は電極（金属）からプラズマです。`Q(sheath_cathode/anode)`は
金属側の電荷で、電子反発シースでは負になります。
`V(metal_minus_plasma_cathode/anode)`はこの電荷と対応する端子電圧です。
Q–Vグラフではこの組を選ぶと正の微分容量を確認できます。
`V(sheath_cathode/anode)`は読みやすいプラズマ−金属の正のシース降下であり、
金属側の電荷と同じ符号の端子定義ではありません。

電子加熱は`<Rbulk Ibulk²>`のみです。シース電荷の可逆なエネルギー、
電源の総端子電力、イオンのシース加速を電子加熱へ入れません。
別項目として電極吸収電力、イオン加速電力、導電シース電力を記録します。
シース電子加熱、二次電子放出、非Maxwell分布、電磁的な伝播・半径方向分布は
未対応です。300 mm・40 MHzの定量評価にはこれらの検討が必要です。

## 純Arの縮約グローバルモデル

モデル版`ar-maxwellian-ground-state-0.1`。固定中性ガス、Maxwell電子分布、
単一Ar⁺イオン、準中性`ne=ni`。Arの粒子収支と電子エネルギー収支を、
RF周期平均の定常解として解きます。着火・マクロな時間発展は未実装です。

```
kion(Te) = 2.34e-14 Te^0.59 exp(-17.44/Te) m³/s
kexc(Te) = 2.48e-14 Te^0.33 exp(-12.78/Te) m³/s
λwall = wall_edge_factor * uB * Aloss / Volume
dn/dt = ne ng kion - ne λwall
Pcollision = ne ng Volume e (15.76 kion + 11.55 kexc)
Pelastic = 3 me/mi * νm * ne Volume e (Te - kB Tg/e)
Pwall = ne λwall Volume e (2.5 Te)
energy balance: Pelectron_bulk = Pcollision + Pelastic + Pwall
```

壁損失エネルギーの2.5Teは電子の2Te＋イオンBohm運動エネルギーの0.5Teです。
RFシースでのイオン加速はここに二重計上しません。電子エネルギー密度は
`we = 1.5 ne e Te`です。粒子収支からTeを求め、RF計算とエネルギー収支を
反復してneを求めます。係数の使用範囲はこの初版で1〜7 eVに制限しています。
密度の探索範囲に根がなければ、値を作らずモデルの収支不成立を返します。

理論の参考文献: M. A. Lieberman and A. J. Lichtenberg, *Principles of Plasma Discharges
and Materials Processing*, 2nd ed. (2005), [DOI](https://doi.org/10.1002/0471724254)。
数値係数はZhaoらの2024年論文の [Table 1, reactions 2–3](https://doi.org/10.7498/aps.73.20240952)
に記載された式・単位（m³/s、TeはeV）と照合しました。同論文の参考文献1は
Lieberman・Lichtenbergのpp.350–351を挙げています。書籍の該当頁は直接閲覧していません。
`coefficient_verification=matched_published_reaction_table`と照合先を結果に記録します。
1〜7 eVは初版の探索制限であり、文献で保証された適用範囲を意味しません。
励起はエネルギー損失として集約し、Ar*密度を時間発展させません。準安定種、
段階電離、ガス加熱・消耗、実測への校正がないため、実験未検証の縮約モデル
として扱います。係数の原典確認と、CCP連成モデルの実験検証は
別です。

## O₂・CF₄とユーザー反応モデル

採用・検証はO₂を優先します。主な壁・電極材はシリコンですが、壁係数には表面状態・表面温度と出典の確認が必要です。[文献調査と採用方針](oxygen-literature-review.md)を参照してください。以下のCF₄対応は現在の試作インターフェースの説明であり、初期版への採用を意味しません。

分子ガスのモデルをArのガス名・質量だけ変えて生成しません。
O₂の文献由来の粒子計算用データを同梱していますが、電子エネルギー収支を含む標準O₂グローバルモデルは未統合・未検証です。CF₄の標準反応セットは未同梱です。
グローバル解析には`analysis.settings.reaction_model`と
`initial_species_densities_m3`を登録してください。未登録時は説明付きエラーです。
固定ne/TeのCCP解析はどちらのガスでも利用できます。

反応エンジンは一次・二体・三体反応のSI単位付き定数とTe依存係数表、準中性条件、粒子収支、
符号付きの電子エネルギー損失、出典付き壁生成物と明示した一次壁損失を扱います。O₂・CF₄には
負イオンと解離した中性粒子種を必須にします。正イオン総電荷と負イオンを
含めた`ne=Σ zs ns`で電子密度を求めます。反応インポート時に電荷保存を確認し、
正の未知密度・温度の対数を変数として定常収支を解きます。

データ形式の例（数値係数を省略した構造の説明で、実行用化学モデルではありません）:

```json
{
  "gas": "O2",
  "name": "研究室のO2モデル",
  "version": "2026-01",
  "source": "出典のDOIまたはデータベースURLと取得版",
  "species": [
    {"name": "O2", "charge": 0, "mass_amu": 31.998, "reservoir": true},
    {"name": "O2+", "charge": 1, "mass_amu": 31.998, "wall_loss_model": "bohm"},
    {"name": "O-", "charge": -1, "mass_amu": 15.999, "wall_loss_s": 100},
    {"name": "O", "charge": 0, "mass_amu": 15.999, "wall_loss_s": 1000}
  ],
  "reactions": [
    {
      "name": "電離",
      "reactants": {"e": 1, "O2": 1},
      "products": {"e": 2, "O2+": 1},
      "electron_energy_loss_ev": 12.07,
      "source": "この反応係数の出典",
      "rate": {"temperature_ev": [1, 2, 3, 5, 7], "coefficients_m3_s": []}
    }
  ]
}
```

全動的粒子種の正の初期密度を`initial_species_densities_m3`に指定します。
実用には電離・解離・付着・脱離・再結合などの閉じた反応セットが必要です。
係数が正なら対数補間、0を含むなら線形補間し、適用範囲外へ外挿しません。
正イオンの既定値は`wall_loss_model="bohm"`で、
`wall_edge_factor * sqrt(e Te/mi) * Aloss/Volume`を使用します。
明示した定数を使うには`wall_loss_model="constant", wall_loss_s=...`を指定します。
負イオンと中性種の既定値はconstantで、一次損失係数をユーザー指定します。
電荷の壁損失から電子の壁損失を閉じます。負イオン壁損失が正イオン壁流束を
超える場合は電子の壁面注入が必要になるため、現在のモデルでは拒否します。
constantモデルの壁損失は回路のBohmシース流束と独立した入力仮定なので、
両者の整合はモデル登録時に確認してください。実際の壁損失係数も結果へ保存します。
電荷数は単価イオンの-1、0、1に制限し、気相反応では小数の電荷数・化学量論係数を拒否します。壁生成物にはO原子からO₂への再結合のような平均生成数の小数を許容し、元素・電荷収支を確認します。
多イオンの回路には密度で重み付けした有効正イオン質量を渡しますが、
電気陰性Bohm条件の補正や多成分シースは未対応です。

出典・データ版・反応表・設定・ネットリスト・収支残差を結果に保存します。
保存したデータセットも`user_supplied_unvalidated`として明示し、解の正値や
収束と化学モデルの物理的な妥当性を区別します。
