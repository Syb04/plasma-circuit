# O₂の損失・収支パラメータスタディ

実施日：2026-10-07。

## 結果と判断

**121通りの独立した入力条件を計算し、118通りで宣言した縮約モデルの収支が整合した。** 同じ入力を基準・単独変更・交差解析に再利用したため、CSVは133行で、独立計算数とは異なる。

今回の探索範囲では、壁へのイオン損失を決めるシース端密度比 `hL=hR` が電子密度・温度へ大きく影響した。弾性衝突損失の変更だけで密度を大きく修正する効果はなかった。次に優先するのは、`hL/hR` を圧力と電気陰性度から求める輸送閉包である。

この結果は、文献の反応係数を固定し、明示した輸送・表面・エネルギー近似の下で得た数値解である。文献モデル全体の再現や、Si電極CCPの妥当性を確認したものではない。

## モデルと計算条件

10重粒子を動的に扱い、電子密度を準中性条件から求める。中性粒子の総密度を `p/(kB*Tg)` に合わせ、純O₂の流入と中性粒子の排気に対して、排気の一次係数も未知数として解く。壁でのイオン中和・原子再結合・準安定分子失活の生成物を気相へ戻す。負イオンの壁損失と荷電粒子の排気は0とする明示近似である。

| 基準入力 | 値・位置付け |
| --- | --- |
| ガス、圧力 | 純O₂、10 mTorr |
| ガス温度 | 600 K（文献条件。表面温度ではない） |
| 円筒形状 | 半径0.152 m、長さ0.076 m |
| 総吸収電力 | 500 W。電子・イオン壁損失を含むプラズマ吸収電力 |
| ガス流量 | 50 sccm。標準状態273.15 K / 101325 Paを明示 |
| `hL=hR` | 0.2。探索用仮定 |
| 拡散係数O / O₂ | 1.2 / 0.84 m²/s。文献10 mTorr計算の参照値 |
| Oの壁再結合確率 | 0.17。SUS上300 Kの測定を原論文が採用 |
| O₂(a)の壁失活確率 | 0.007。Fe上の測定を原論文が採用 |
| 運動量衝突頻度 | OとO₂にそれぞれ10⁷ s⁻¹。合計2×10⁷ s⁻¹の仮定 |

化学反応はGudmundssonら(2001)の11種・49反応を記録したデータに基づき、未解決のk49を除く48反応を使った。原文との正規化・修正候補は結果JSONに保持している。化学反応係数を測定値へ合わせて調整していない。

エネルギーは原論文式(3)型の縮約式で、基底O/O₂の電離、参照論文の励起16項、明示した弾性衝突、電子・イオン壁損失を合算する。壁の電子平均エネルギーを2Te、イオンをφ+Te/2とし、φは電子流束と正イオン壁流束を合わせて求める。励起表に含む解離を別項として二重加算しない。電離閾値は補足NIST値で、率式の指数の値を代用していない。

この式は全48反応の反応別エネルギー表ではない。励起種電離、脱離、超弾性衝突等のエネルギーが完全には与えられていないため、完全な電子エネルギー収支と区別する。

## 文献の密度値との比較

原論文本文のO₂⁺密度は、10 mTorr・500 Wで5.7×10¹⁶ m⁻³、100 Wで2.9×10¹⁶ m⁻³。原論文はこの数値の不確かさを示していない。下表は符号付き相対差であり、合否基準として使っていない。

| h（同じ値を両電力に適用） | 500 Wの文献値との差 | 100 Wの文献値との差 |
| --- | ---: | ---: |
| 0.05 | −14.05% | +20.96% |
| 0.1 | +2.40% | +7.68% |
| 0.2（基準） | +8.53% | −13.24% |
| 0.4 | −4.00% | −38.07% |

h=0.1は10 mTorrの2電力で近接する仮定の一例だが、検証済みの定数として採用しない。1 mTorrではh=0.1、0.2、0.4の3条件が温度上限に達し、係数適用域内の整合解を取得できなかった。h=0.05の1 mTorrケースは数値収支が整合するが、O₂⁺密度は1 mTorr・500 Wの文献値に対して−74.56%であり、数値的整合と文献一致の違いが明確である。

**圧力をまたいで単一hを固定するだけでは、この範囲で文献の再現を示せていない。** hの圧力・電気陰性度依存と、組成に対応する輸送の導出を優先する。

## 数値判定と独立検算

判定は最適化の終了フラグだけで行わない。全粒子の生成・損失、電子、エネルギー、中性圧力、酸素原子数、準中性の相対残差を各々10⁻⁶以下とし、正の粒子密度・排気、非負のシース電位、探索下限への張り付きを確認した。

原論文本文3.4節のk20には `1<Te<4.5 eV` の個別適用域があるため、表の総論1–7 eVより厳しく制限した。温度境界に張り付いた結果は失敗として残し、文献偏差・感度図の有効結果から除外した。失敗はその仮定・初期値群で整合解を取得できなかったことを意味し、放電が物理的に存在しないことの証明ではない。

成功118入力について、別コードで48反応のイベント率・壁生成物・流入排気・損失内訳・電子流束を再計算した。最大再計算差は反応率2.9×10⁻¹⁴、損失内訳1.4×10⁻¹⁴で、単位や二重計数の整合を確認した。

| 成功入力の最大相対残差 | 値 |
| --- | ---: |
| 粒子 | 4.1×10⁻¹² |
| エネルギー | 9.6×10⁻¹⁴ |
| 酸素原子 | 4.2×10⁻¹¹ |
| 中性圧力 | 1.8×10⁻¹³ |
| 準中性 | 8.0×10⁻¹⁷ |

実装・データ・ガードのテストは70件合格（既存実ソルバー2件をこのコマンドでは除外）。実行データにはソルバー・元データ・スタディコードのSHA-256、全入力、失敗理由、損失内訳、収支残差を保存した。hL/hRを共通イオン種へ使う今回の近似では有効面積の組合せが効くため、この結果だけでhLとhRを独立同定できない。

## 次のモデル改善

1. 電気陰性シース端と圧力依存の輸送からhL/hRを計算し、複数圧力・電力で同じ閉包を試す。
2. 弾性衝突頻度を組成・EEDFから計算する。今回の10 mTorrでは密度感度が小さく、単純なνの調整を主な較正手段にしない。
3. k49の原典確認と反応別エネルギーの不足を解消し、より完全なO₂反応系へ進める。
4. Si表面の状態・温度・係数を扱い、CCPのRF吸収電力を回路計算と連成してから目標装置条件を評価する。
