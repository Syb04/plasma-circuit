# 指数入力・詳細ダイオードの検証

回路素子の数値入力を、入力途中の指数を保持する共通テキスト入力へ変更した。正負の指数、`e` / `E`、符号付き小数を受け付け、完成した有限のSI数値を回路・解析条件へ渡す。波形の周波数・立上り・立下り・ON幅・周期、通常素子、PLASMA部品、解析の数値欄を対象にした。無効な表示中の数値欄がある場合は保存・計算を停止して欄を示す。

「ダイオード（詳細設定）」を追加した。IS / N / RS / BV / IBV / CJO / VJ / M / TT / EG / XTI / FC / TNOMを設定し、各部品に独立したngspice Dモデルを生成する。従来のモデル名参照も維持した。空欄のモデルパラメータは定義から除き、ngspice既定値を使う。追加時のBVは未指定。

操作・単位・入力範囲は[回路素子のパラメータ](../../docs/circuit-parameters.md)を参照。

## 最終Docker環境

[配備・テスト記録](deployment.json)と[ブラウザ検証記録](verification.json)に、イメージ、フロントエンド資産、ソースSHA-256、実run IDを保存した。API・workerは同じ最終イメージを使用し、DB・キューのhealthは正常。既存の保存データを維持した。

```bash
docker compose -f compose.yaml -f compose.cloud.yaml run --rm --no-deps api \
  python -m pytest tests/test_engine.py tests/test_api.py tests/test_workflows.py tests/test_external_rf.py -q --tb=short
```

**163件合格、29.59秒。** Starlette / anyioの既存非推奨警告1件。全バックエンドスイートの再実行数ではなく、今回の素子コンパイル・解析・保存・研究・外部RFに関係する4ファイルの検証数である。

主な追加検証は、IS・Nが異なる3ダイオードの順方向電流とShockley式との比較、BV=6 V・IBV=1 mAでの逆降伏、面積倍率とRSの順方向電圧、逆バイアス接合容量のACアドミタンス、未知・重複・非有限・範囲外モデルパラメータの拒否、モデル名衝突と既存DDEFAULT参照、波形・モデルパラメータの保存と実行後編集に対するスナップショット保持。

実検証で確認した互換性の修正も含む。D素子の面積を `AREA=...` と明記し、ngspice 44で位置指定の面積が別モデル名と解釈される問題を解消した。DC値と波形開始値の違いに関する特定のngspice注記をPySpice 1.5がエラーとする場合は、要求した解析の実計算済みデータが存在することを確認して取得し、注記を結果ログに保持する。動作点・DC・AC・過渡を実ソルバーで確認した。未知の注記や計算エラーを一般的に無視する処理ではない。

## 実ブラウザ・実キュー

```bash
python scripts/check_source_diode_ui.py --base-url http://localhost:8080
```

**9チェック合格。** API・ソルバーのmockなし、ブラウザ実行時エラーなし。40 MHz正弦波は212サンプル、パルスは6,057サンプルで、PySpice 1.5 / ngspice 39による実計算が成功した。どちらもDC値と波形開始値が異なる条件を含み、注記がログに残ることを確認した。

- `4e`、`1e-` の途中状態を一文字ずつ入力して保持し、`4e+7`、`1e-9` へ完成できる。
- 通常素子と詳細ダイオード13項目で指数入力を使用できる。ライト／ダーク・デスクトップ／390 px幅のモバイル表示を確認した。
- 未完成・非有限・16進・数値下限外の文字列では、保存・実行のAPIへの書込を発生させない。
- 波形・ダイオードはPostgreSQLと実行スナップショットに数値で保存され、生成モデルを結果ネットリストで確認できる。
- 入力したパルスの遅延・立上り／立下り・幅・周期を使って計算し、ON区間の電源電圧2.5 V、OFF区間0 Vを確認した。
- 一覧ページから再読込して素子・波形・物理時間を復元できる。BVを空欄にして保存すると上書きパラメータが除かれ、過去runのBV=75 Vは保持される。
- RF・第2RF・包絡の指数入力、任意の包絡周波数を空欄にして保存する動作を確認した。

[共通入力の追加回帰確認](controls-regression.json)は**3チェック合格**。電流源のA / Hz数値、PLASMAのmTorr→Paと電子密度・RF周期数、時間発展0Dの全5単位切替と空の任意RF再評価間隔を確認した。これらはUI確認のみで、DB書込や追加プラズマ計算は行っていない。

検証に使用した最終モデル1件と実run 2件をDBに保持した。途中の検証スクリプト調整で作成した、この作業専用のモデル3件・run 4件・版10件は、社員番号・名前・参照・終了状態を確認して削除した。
